
# PoseLoom
Распределённая система захвата движения по видео (загружаемый файл или видеопоток в реальном времени): обычный видеоролик/поток превращается в анимацию скелета и применяется к целевому ригу — в клиентском приложении или через Unity-плагин. Разворачивается дома или на удалённом сервере.

## Пайплайн

    видео → 2D → аплифтер → 6D-вращения+IK → риг

1. **2D-оценка позы** — для каждого кадра видео извлекаются 2D-координаты ключевых точек и confidence-оценки.
2. **Нейросетевой IK-солвер (learned / amortized IK)** — по 2D-ключевым точкам сеть прямым проходом предсказывает решение обратной кинематической задачи — локальные вращения суставов в 6D-параметризации. Обучение учитывает кинематику скелета: фиксированные длины костей, анатомические ограничения подвижности суставов, согласованность 3D-позы с 2D-наблюдениями и, при необходимости, временную гладкость. В отличие от классического IK, решение не ищется итеративно, а аппроксимируется сетью.
3. **Реконструкция позы по вращениям (FK) и контроль ограничений** — предсказанные вращения применяются к скелету с фиксированной топологией и длинами костей; прямой кинематикой вычисляются 3D-положения суставов. На выходе — кинематически согласованная поза.
4. **Ретаргетинг на целевой риг** — анимация переносится на целевой скелет в рантайме клиентского приложения или в Unity-плагине.

## Компоненты
- **Серверная часть** — приём и хранение видео, оркестрация узлов анализа
  (Java / Spring Boot, PostgreSQL, MinIO).
- **Узел анализа** — ML-конвейер: 2D-поза, аплифтер, IK (Python-стек).
- **Клиент** — применение результата к ригу: standalone-приложение / Unity-плагин.
